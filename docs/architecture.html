Factory Inventory Management System

Architecture overview — tech stack, system layers, and data flow

Tech Stack

Frontend

Vue 3 SPA

  • Vue 3 — Composition API
  • Vue Router — client-side routing
  • Axios — HTTP client
  • Vite — dev server & build
  • Runs on :3000
Backend

FastAPI Service

  • FastAPI — REST API framework
  • Pydantic — request/response validation
  • Uvicorn — ASGI server
  • CORS enabled for local dev
  • Runs on :8001
Data

In-Memory Mock Data

  • JSON files in server/data/
  • Loaded once at startup into Python lists
  • No database — changes reset on restart
  • Covers inventory, orders, demand, backlog, spending

Design Notes

No database layer

  • All data lives in server/data/*.json, loaded into memory once at startup
  • Writes (e.g. purchase orders) are not persisted across restarts
  • Keeps the demo self-contained — no setup beyond uv and npm

Cross-cutting frontend concerns

  • useFilters — shared filter state across views
  • useAuth — mocked current-user session
  • useI18n — English / Japanese localization
  • Scoped component styles, Slate/gray design system
